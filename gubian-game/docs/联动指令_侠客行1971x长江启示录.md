# 《侠客行1971》×《蛊变：长江启示录》联动支线 · 制作指令

> 支线暂名：**「丹字档案」**（三段式）
> 用途：第一部分是可以直接粘贴给《侠客行1971》开发 AI（Codex / Claude 等）的执行指令；第二部分是双方共用的世界观对接设定；第三部分是《长江启示录》这边的回扣点。
> 两部作品同属「启示录三部曲」。本支线是**游戏改编提案**，不改写《侠客行1971》源小说正史，也不改写《长江启示录》已有剧本。

---

## 〇、一句话概括

1940 年宜昌失守后，日军 731 部队派出一支伪装成药材商的秘密分队，代号「**丹字班**」，经三峡潜入川东丰都。他们在名山脚下的江边崖墓里，挖出了楚巫用来“送魂”的朱砂菌，并用掳来的民夫和百姓做活体试验，造出最早的生物兵器“**丹奴**”。

1945 年投降时，丹字班炸毁了溶洞，但样本和实验记录被日系秘密结社「**能面众**」接手。1971 年，能面众在上海准备把封存的样本“丹-7”运回上游，交给下家。唐武男截下了这批货，却漏掉了一支。

1976 年，这支样本在一次“楚墓考古”中“重新出土”，「万蛊计划」由此立项，后来成了百慧集团。2026 年，《长江启示录》的全面爆发由此而来。

## 三、《长江启示录》这边的实现情况

> 已经做成可玩内容：主菜单「联动支线 · 丹字档案」三幕（外滩·十六铺夜运 / 船舱·逆流 / 丰都·名山溶洞），玩家操作唐武男，美术取自《侠客行1971》v0.4。下面是主线里的回扣点：

   - 新增一份可阅读档案《丹字班交接清单（复印件）》，清单末尾的“丹-7”被红笔圈出，旁注“CG-7”。

2. **第三章 · 丰都江段**（未做）：在江岸崖壁上加一个能面面具的彩蛋，勘察（C）后弹出唐武男 1971 年的现场报告残页。
