# 《蛊变：长江启示录》· Doom 风格第一人称恐怖射击（全八章）

根据剧本《蛊变：长江启示录》V1.0 与配套美术资产制作。玩法参照经典 Doom：网格迷宫关卡、钥匙门、暗门、自动地图、出口结算；节奏按恐怖游戏调整为慢速推进，加入跳脸惊吓、过场动画和每章结算画面。

**电脑版与手机版是两个独立的构建**，操控界面互不混用：

| | 电脑版（Windows） | 手机版（安卓） |
| --- | --- | --- |
| 构建模式 | `vite build --mode desktop` → `dist-desktop/` | `vite build --mode mobile` → `dist-mobile/` |
| 打包 | Electron → 安装版 / 免安装 exe | Capacitor → APK |
| 操控 | 键盘 + 鼠标（指针锁定）/ Xbox 手柄 | 浮动摇杆 + 滑动视角 + 触控按键 |
| 界面 | Doom 式底部状态栏（头像、生命、护甲、弹药、钥匙） | 顶部精简信息条，底部留给触控按键 |
| 存档 | `gubian.desktop.save.v2` | `gubian.mobile.save.v2` |

## 美术与音效

- 角色、感染体、首领：从用户提供的高清设定图中用 AI 抠图（rembg / ISNet）得到透明立绘，游戏内为始终面向镜头的立绘（Doom 式），并做了像素级命中判定（头部、首领弱点区域单独判定）。
- 第一人称持枪手、铜铃手、冷凝枪、重机枪：取自用户提供的第一人称插画和武器手模。
- 墙面贴图、过场画面：取自用户提供的场景插画和宣传视频画面；主菜单可观看宣传片，第一章开场直接使用该视频。
- 角色头像：取自美术总览图；对话字幕带头像。
- 音效：用户提供的手枪、冷凝弹、勘察镜、铜铃 wav，加上程序合成的环境音、嘶吼、心跳和跳脸尖叫。

## 关卡校验

`npm run validate` 会对八章地图逐一检查：

- 每扇门的门框是否正确（不会被家具或墙堵住门口）；
- 按剧情推进模拟：钥匙拿得到、钥匙门打得开、剧情门的触发点到得了；
- 出口和剧情路线上的每个点都可以到达；
- 物品、暗门里的奖励、刷怪点和剧本里引用的位置不会嵌在墙体或家具里；
- 剧本里用到的位置点和敌人种类都存在。

CI 每次打包前都会先跑这项校验，校验不过就不出安装包。

## 本地开发

需要 Node.js 22+。

```bash
cd gubian-game
npm install
npm run dev            # 电脑版（浏览器打开 http://localhost:5173）
npm run dev:mobile     # 手机版界面（用浏览器的手机模拟或真机访问）
npm run validate       # 关卡校验
npm run electron       # 以 Windows 桌面程序方式运行
npm run dist:win       # 在 Windows 上打包 exe（输出到 release/）
npm run android:init   # 生成安卓工程（需要 JDK 21 + Android SDK），随后 cd android && ./gradlew assembleDebug
```
