# 《蛊变：长江启示录》第一章 · 云梦号

根据剧本《蛊变：长江启示录》V1.0 制作的**第一人称丧尸惊悚射击游戏**，可在 **Windows 电脑** 和 **安卓手机** 上运行。
当前版本完整实现了第一章「云梦号」（约 15–20 分钟流程）。

> 剧本原定为第三人称越肩视角，这里按需求改为第一人称；剧情、角色、台词和关卡节拍都按剧本第一章改编。

## 游戏内容

| 剧本场景 | 游戏里的实现 |
| --- | --- |
| 场1 长江江面 | 黑屏 + 江水声开场，陈砚在耳麦里报告热成像 |
| 场2 甲板（教学一：移动与观察） | 雾夜甲板、船艏红灯、散落的高跟鞋和酒杯、血迹；查看手机里的最后一段视频 |
| 场3 宴会厅（教学二：战斗瞄准 / 教学三：勘察镜） | 两排背对你一动不动的宾客，三名蛊化者依次苏醒；解锁**勘察镜**与**手电强光**（蛊化者畏光） |
| 场4 走廊 / 客房 | 探索客房，拾取弹药、草药、**档案一：乘客名单**、底层钥匙卡 |
| 场5 客房 | 在衣柜里找到小满；**铜铃**驱散蛊化者（冷却 60 秒） |
| 场6 后厨冷库（小 Boss：屠夫） | 正面厚甲；引诱它冲撞**冷凝管**或射击冷凝管使其失衡，再打背部**朱砂囊泡**；击败后老周登场 |
| 场7 驾驶舱 | 舵盘自转、雷达、“净江者”广播、船底巨响 —— 第一章完 |

其他特性：

- 全部美术、贴图、音效都在运行时程序化生成，不依赖外部素材（安装包很小）
- 3D 空间音效：蛊化者嘶吼、铜铃、心跳、江水与船体呻吟
- 爆头三倍伤害、命中反馈、检查点与死亡重来、通关统计
- 画质分低 / 中 / 高三档（高档有实时阴影），可调灵敏度和音量，手机默认开启辅助瞄准

## 操作

**电脑**：WASD 移动 · Shift 奔跑 · 鼠标 视角 · 左键 射击 · 右键 瞄准 · R 换弹 · E 互动 · Q 勘察镜 · F 手电强光 · G 铜铃 · H 草药 · Esc 暂停 · F11 全屏

**手机**：左半屏拖动是虚拟摇杆（推到底奔跑），右半屏滑动转视角；按住「开火」射击时也可以拖动瞄准；技能按钮解锁后出现。

## 下载安装包（推荐）

每次推送到 GitHub 后，GitHub Actions 会自动打包：

1. 打开仓库的 **Actions** 页面 → 选择 **Build 蛊变 (Windows + Android)** 最近一次成功的运行
2. 在页面底部的 **Artifacts** 下载：
   - `GuBian-Windows`：内含安装版 `GuBian Setup x.x.x.exe` 和免安装的 `GuBian-Portable-x.x.x.exe`
   - `GuBian-Android`：内含 `GuBian-Android.apk`，传到手机上安装（需要在系统设置里允许“安装未知来源应用”）

> 安卓包是 debug 签名，适合自己安装测试；要上架应用商店需要换成正式签名。

## 本地开发

需要 Node.js 22+。

```bash
cd gubian-game
npm install
npm run dev          # 浏览器打开 http://localhost:5173 直接玩
npm run electron     # 以 Windows 桌面程序方式运行
npm run dist:win     # 在 Windows 上打包 exe（输出到 release/）
npm run android:init # 生成安卓工程（需要 JDK 21 + Android SDK），随后：
cd android && ./gradlew assembleDebug
```

## 代码结构

```

  main.ts              菜单、设置、启动
  game/game.ts         主循环、玩家、射击、技能、检查点

  game/weapon.ts       手枪第一人称模型与弹药
  entities/enemy.ts    蛊化者与屠夫 AI
  entities/companion.ts 苏晚、小满、老周
  world/map.ts         云梦号网格地图、碰撞、寻路
  world/level.ts       关卡几何、灯光、门、冷凝管
  core/audio.ts        程序化音效
  core/input.ts        键鼠与触屏输入
  ui/hud.ts            HUD、字幕、档案阅读
electron/main.cjs      Windows 桌面外壳
scripts/patch-android.mjs  安卓横屏全屏配置
```
