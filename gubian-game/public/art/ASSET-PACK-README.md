# 蛊变：长江启示录 · 慢节奏 Doomlike 恐怖重制

当前阶段：先制作可独立使用的美术单体。此目录目前是资产包，不是完成的游戏安装包。

## 已确定的方向

第一人称、三维关卡、二维精灵人物与敌人、第一人称武器。保留长江流域、云梦号、七二一厂、朱砂菌群、铜铃和血清的剧情设定。

节奏以缓慢推进、探索、观察、有限弹药和环境惊悚为主。常态不是高速冲刺清怪。以脚步、呼吸、广播、电流声、逆光剪影和光线变化提前建立不安，再在关键位置安排少量有铺垫的跳脸事件。

保留过场动画。后续采用独立二维人物与场景分层、人物位移、镜头移动、道具变化、对白和声音制作，风格与游戏精灵一致。正式过场动画仍未制作。

电脑版与手机版继续采用独立操控界面和输入，不再把触控按钮放在电脑画面里。

## 第一批 15 个独立资产

- 人物 4 张：林骁、苏晚、老周、陈砚。
- 感染体 4 张：蛊化者、矿蛊、傩面者、腐妆新娘。
- 惊吓特写 1 张：傩面惊吓特写。
- 第一人称武器 2 张：制式手枪、化学冷凝枪。
- 道具 4 张：云雷纹铜铃、血清瓶、弹药补给箱、急救包。

每个资产只有一个主体，分别保存为 RGBA 透明 PNG。没有用一张人物拼图替代独立素材。人物保留完整头部和脚部；武器采用后侧第一人称视角。原始选定输出逐字节复制，不进行隐式背景抠图或再次压缩。

制作工具：内置 image_gen。完整生成与修正提示词在 `asset-source/manifest-input.json`；文件尺寸、透明主体范围、建议脚底锚点和 SHA-256 在 `assets/manifest.json`。

## 用途与尚未完成的部分

`characters/` 用于对话人物和过场分层；`enemies/` 的全身图用于场景中的精灵敌人，面具特写用于近距离惊吓覆盖层；`weapons/` 用于第一人称武器显示；`props/` 用于拾取物和剧情道具。

本批是静态基础图，不包含行走、攻击、受击、死亡或八方向动画序列。四名主角与这四种感染体以外的 NPC、首领、场景分层、门、开关、特效和正式过场素材也尚需制作。不能把静态资产数量视为完整游戏或完整动画已完成。

预览图中的灰色卡片只是用于检查透明边缘，独立 PNG 不含这些背景。提示词和原始生成路径保留用于追溯，运行游戏时不应依赖原始生成缓存路径。
