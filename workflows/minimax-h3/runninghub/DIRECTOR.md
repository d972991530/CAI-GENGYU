# H3 导演台 · 镜头人物替换

`h3_director_console.json` 把动作迁移工作流改成按镜头操作的导演台：切割包里的 78 个镜头各对应一个分组，每组有自己的素材上传口，可以逐个镜头替换画面里的人物。

## 文件

| 文件 | 用途 |
|---|---|
| `h3_director_console.json` | 导演台工作流，导入 RunningHub / ComfyUI |
| `build_director_console.py` | 生成导演台的脚本；改镜头表或布局后重新运行 |
| `shot_list.json` | 78 个镜头的入点、帧数、时长 |
| `assemble_director.py` | 把生成的镜头拼回成片，没生成的镜头用原片补上 |

配套素材在两个压缩包里：镜头切割包（`clips/shot_NNN.mp4`）和导演台素材包（`first_frames/shot_NNN.png`，每个镜头的第一帧原图）。

## 画布结构

- **全局设置**（最上方一组）：H3 模型链、Turbo LoRA、采样器、两段全局提示词、画面宽高（默认 1536×672，与原片同比例）。
- **镜头开关面板**：rgthree 的 Fast Groups Muter，列出全部「镜头 NNN」分组，点一下开关。
- **镜头 001–078**：每组一个镜头，默认关闭。

每个镜头分组里：

| 节点 | 说明 |
|---|---|
| 原片镜头 | 上传 `shot_NNN.mp4`，作为 `<Video 1>` 提供动作、镜头运动和节拍（`<Audio 1>`） |
| 主参考图 `<Picture 1>`（必填） | 替换人物后的第一帧，决定镜头里每个人的长相、服装和站位 |
| 额外参考 2、3（可选） | 默认没接线；需要时连到 H3 节点的 `ref_images.ref_image_1/2`，提示词里用 `<Picture 2>/<Picture 3>` 指代 |
| 镜头提示词 | 已写好镜头编号和时长，可补充人物对应关系 |
| H3 Ref2VA → 采样 → 解码 → 裁回原长 → 输出 | 生成帧数已按镜头算好；不足 124 帧的镜头先生成 124 帧再裁回原长 |

## 一个镜头的完整流程

1. 从 `first_frames/` 取出该镜头的第一帧，用图像编辑模型把画面里的人换成你的角色（背景、构图、姿势保持不变），作为主参考图上传。
2. 上传同编号的原片镜头。
3. 需要的话补充镜头提示词。
4. 在开关面板里打开这个镜头，运行。可以一次打开多个镜头，会按顺序逐个生成。
5. 全部做完后，把 RunningHub 输出目录下载下来，运行：

   ```bash
   python3 assemble_director.py --clips 切割包/clips --renders 输出目录 --source 原视频.mp4 --out final.mp4
   ```

## 为什么额外参考口默认不接线

ComfyUI 运行前会检查所有接到输出上的「加载图像」节点，文件不存在就整个任务报错，即使中间有开关跳过它也一样。所以可选的上传口只能先不接线，用到时再连。分组的启用和关闭会覆盖节点的忽略状态，也不能靠「默认忽略」实现。

## 注意

- 我没有在 RunningHub 上实际运行过。节点名和接口都对照了原工作流和 ComfyUI 源码，连线做过自动校验。
- 开关面板依赖 rgthree-comfy。如果平台没装，这个节点会显示为缺失，不影响其他部分；可以改用右键分组 →「设置分组节点为总是执行」来打开镜头。
- 很短的镜头（1 秒以内）生成 124 帧再裁回，相当于多花几倍算力。
- 替换用的角色需是虚构人物，或已获得本人授权的人物；原片的画面、编舞和音乐有版权，公开发布前需取得授权。
