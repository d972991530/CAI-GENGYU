# 参考素材清单

路径与 `shots.json` 的 `references` 一一对应。建议用同一个出图模型、同一套设定批量生成，保证 12 人长相稳定。

| 文件 | 内容 | 建议规格 |
|---|---|---|
| `members/A_c1.png` … `H_c1.png` | 成员 A–H，第一套服装（白色宽松卫衣 + 卫裤） | 纯色背景，正面全身或七分身，竖构图，短边 ≥ 1024 |
| `members/A_c2.png` … `L_c2.png` | 成员 A–L，第二套服装（灰白 Polo 短上衣、百褶短裙、白色长袜、乐福鞋） | 同上 |
| `group/group_c1.png` | 12 人第一套服装合影，一字排开 | 横构图，脸要清楚 |
| `group/group_c2.png` | 12 人第二套服装合影 | 同上 |
| `scenes/white_cyc.png` | 纯白无缝影棚 | 1344×768，无人 |
| `scenes/black_void.png` | 黑场加顶光 | 同上 |
| `scenes/capsule.png` | 灰蓝太空舱，弧形白墙带圆孔 | 同上 |
| `scenes/blue_arena.png` | 蓝色环形竞技场，地面发光路径和节点 | 同上 |
| `keyframes/end_AB_L.png` | 尾帧：A、B 第二套服装，在蓝色竞技场里对镜头比 L 手势 | **必须正好 1344×768**，会成为成片最后一帧 |

成员 I–L 只在第二章出场，所以只需要第二套服装的定妆照。
