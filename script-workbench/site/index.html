常见问题

需要付费吗？

应用免费。AI 调用使用你自己的 API Key，费用由对应的 AI 服务商按用量收取。

在中国大陆能用吗？

DeepSeek 可以直接使用。Claude、GPT、Gemini 的官方接口在中国大陆无法直接访问，需要能访问境外网络的环境，或在设置里换成你信任的兼容中转地址。

我的剧本和 Key 存在哪里？

都只保存在你的手机上。写台词或分析时，相关内容会直接发给你选择的 AI 服务商，不经过任何其他服务器。

怎么更新？

应用打开时会自动检查新版本，有更新会提示下载。也可以在「设置 → 关于 → 检查更新」手动检查，或回到本页下载最新版覆盖安装，数据不会丢。

之前装过 1.0 原版，装不上新版？

最早的 1.0 原版签名不同，需要先导出需要保留的数据、卸载旧版，再安装本页的版本。之后的更新都可以直接覆盖安装。
