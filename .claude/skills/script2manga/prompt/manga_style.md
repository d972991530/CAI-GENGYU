# 手绘风格库

每个二级标题（`##`）是一个可选风格，标题文字就是 `style_controller.py` 里用来查找的风格名；标题下的正文是喂给出图模型的风格描述词块。新增一种风格只需要在这里加一节，不需要改代码。

## 日式漫画

黑白网点漫画风格：清晰锐利的墨线勾边，人物眼睛与发丝用高密度网点(screentone)表现明暗层次，速度线与集中线用于强调动作与情绪冲击，背景以简洁的线条透视或大面积留白处理，分镜边框干净利落。

## 美式漫画

粗犷有力的墨水笔触，强对比的明暗分割(chiaroscuro)，大量交叉排线(cross-hatching)表现阴影和肌肉体积，构图强调透视张力与英雄式仰角，分镜边框常带有轻微的手绘不规则感。

## 欧式漫画

Bande dessinée 风格：细腻写实的钢笔线条，水彩或平涂上色，注重环境与建筑透视的准确还原，人物表情克制内敛，分镜节奏偏慢、留白讲究，整体气质文学化。

## 水彩手绘

湿画法水彩渲染，柔和的色彩晕染与不规则边缘，铅笔草稿线若隐若现，情绪氛围优先于细节精度，适合抒情、回忆、梦境类段落。

## 铅笔素描

未上色的铅笔草图质感，可见的构造线与反复修改的痕迹，明暗靠排线与涂抹表现，纸张纹理明显，适合分镜草案阶段或强调"未完成/记忆碎片"的叙事效果。
